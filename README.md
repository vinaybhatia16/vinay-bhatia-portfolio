# Vinay Bhatia Portfolio

Minimal portfolio inspired by the structure and editorial feel of piyushgiitian.vercel.app, with original copy and styling for Vinay Bhatia.

## Run locally
Use any static server, or simply open `index.html`.

For Vercel:
- Import this folder/repository.
- Framework preset: Other
- Build command: leave empty
- Output directory: `.`
